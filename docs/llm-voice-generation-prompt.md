## 二、允许使用的词汇与客观事实规则

### 1. 世界观与领地规范
* 世界观空间一律使用「领地」或「据点」。
* 房屋与设施一律使用「工坊」、「水井」、「厨房」、「库房」、「农田」、「木门」、「窗户」。

### 2. 西幻温婉生活词汇规范
* **日常与关切**：工作、手头的事、帮忙、吩咐、整理、收拾、休息、散步、闲坐。
* **起居与保暖**：炉火、炭火、火盆、烤火、外套、斗篷、衣服、针线、换洗衣物、关好窗户、早些安歇。
* **饮食与器具**：清水、清凉的水、热水、香草茶、热汤、麦粥、面包、咸肉、大头菜、甜菜、扁豆、陶罐、木盆、碗、木勺。南弗洛里亚鸭肉炖豆子（卡索尔）、柠檬风味蛋糕（菲亚多内）。菜园架子使用木条或木架。
* **自然时令与时节**：太阳、阳光、下雨、落雪、雪水化开、树叶、泥土、春天、夏天、秋天、冬天、早晨、正午、夜里。时间使用一会儿、好一阵子。
* **连词与假设**：如果、要是、有时间的话。
* **法师专用（赛琳）**：工坊、羊皮纸、松烟墨水、羽毛笔、符文、阵图、笔道、弯纹、照明石、药水、止血水、布签、法杖、木椅、案台、长桌。
* **口语生活词汇**：
  - 采掘与石材：岩壁嵌着碎晶石、石头质地松脆、好下镐、敲凿省力。
  - 时令与体感：天凉、天暖、风大、天阴、雪落得厚、雪水化开、屋里暖和、清凉适宜。
  - 农事与田园：菜垄、引水沟渠、浇水、翻土、泥土松软好下锄、大头菜长得壮实。
  - 起居慢生活：香草茶、烤麦饼、拭净长桌、添柴拨火、散步看红叶。
  - 咒文与研习：字音、声调、呼吸、手势、光芒、法术回路、药典、图谱、古卷。

### 3. 面对面自然交谈与句式多样性规则
* **真人面对面口语（二次元西幻生活口语准则）**：
  - 台词由同伴**当面与大人交谈时自然说出**，具备二次元轻小说般的温和亲切感与慢生活情调。
  - 围绕日常关怀、饮食分享、时令闲话、技能请教与陪伴展开。
  - 璐米埃尔日常：
    - 「早上好，大人。」
    - 「大人，今天有什么事情要交待我吗？」
    - 「洗好的被单已经收进屋了，叠得整齐。」
    - 「如果是做饭的话，我稍微有些心得哦。」
    - 「今天煮了热腾腾的扁豆浓汤，大人要尝尝吗？」
    - 「森林里的树叶都染红了，非常美丽，大人有空一起去走走吗？」
    - 「很意外吗？搬重东西……其实是我的强项。」
    - 「嚼嚼……。失礼了，大人请稍等一下哦。」
  - 赛琳日常：
    - 「大人，请问有什么事吗？」
    - 「大人早，我刚把昨晚的药典抄录整齐。」
    - 「大人进工坊小心些，地上有些刚凿开的矿石渣。」
    - 「大人，长桌我已经擦拭干净了。」
    - 「这道阵图画起来好费劲，笔道总是容易描歪。」
    - 「以前在学院只能啃硬黑麦面包，这里的热汤好喝多了。」
    - 「荧石粉碾得细致，装在陶罐里备用。」
    - 「刚给这几瓶止血水贴好布签，大人带在身边备用。」
    - 「魔力从指尖引出来，再慢慢收回。」

### 4. 句式结构与去套路化许可标准
* **句式长短错落**：短单句、双分句、疑问句交替出现，结构自由多变。
* **句尾自然收束**：句尾收束多样，允许使用单字句号、疑问句（？/ 吗）、语气助词（呢 / 哦 / 吧 / 了），保持日系轻文学译体的温和轻柔。
* **用词清爽雅致与日常自然动词规范**：
  - 动作叙述纯用日常通畅的完整动词短语：拉过双手、握住手掌、抱在怀里、亲了亲脸颊、凑近吻了吻嘴唇、摸了摸头发、理顺发丝。
  - 描写具体真实可见的肢体反应：低下了头、脸颊泛起红晕、双手抓紧围裙角、局促地缩起双肩、安静地任由握着、眼睫垂下带着浅浅笑意。
  - 动词与修饰词完整平实，使用人人皆懂的日常口语与叙述体，专注于朴实生动的生活动作。
* **角色独立特色与句式彻底分流**：
  - 璐米埃尔 none 组采用四种不同的人际应答语气：井台清凉晨水交代、被单收纳交代、地潮提醒走稳、热茶滚开招待。

  - 赛琳 work 组分别采用不同的劳作句式与视角：底架陶罐储粉说明、止血水布签备用、整洁案台药渣清倒。

## 三、两类文本结构规则

1. **角色台词（Speech）**：
   * 角色直接开口说话的原声。
   * 允许使用中文逗号、句号、感叹号、问号、省略号。
2. **系统叙述（Narration/State）**：
   * 记录谁在什么地方做什么动作的客观陈述（如：璐米埃尔在案板前切咸肉、赛琳在桌前看书）。
